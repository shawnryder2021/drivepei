# DrivePEI visual identity

The site uses the user-supplied transparent DrivePEI logo at `public/images/drivepei-logo.png` without altering the source artwork. It appears in the header and on a white panel in the dark footer.

Core colours sampled from the logo:

| Role | Hex |
| --- | --- |
| Navy | `#003B66` |
| Green | `#1E8532` |
| Aqua | `#18A0D0` |
| White | `#FFFFFF` |

The interface uses lighter shades of these colours for legible text on dark backgrounds and pale blue section backgrounds. The compact favicon uses the same palette.
